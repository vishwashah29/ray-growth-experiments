# RAY Growth Experiments

Interactive prototype for the Razorpay AI PM Build Challenge.

The prototype shows how a merchant moves from a RAY WhatsApp recommendation to comparable merchant evidence, an AI-prepared experiment in the Agentic Dashboard, a Magic Checkout preview and approval, and a measured result.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript, with `razorpay-logo.png` as its only local asset. There are no dependencies or build steps.

## Demo scope

The House of Ayam is an illustrative merchant. All checkout, peer and experiment figures are synthetic. The prototype does not connect to Razorpay or change any live settings.
